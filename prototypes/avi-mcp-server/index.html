Model Context Protocol server

Nine tools.
Every Avi object.

Avi Load Balancer's REST API has 170 object types — all following the same shape. So this server doesn't ship 170 one-off tools. It ships nine generic ones, and reaches all 170.

how the api shapes up the nine tools full coverage
Why nine is enough

Every object type is the same shape

Pull the Swagger spec off any Avi Controller and the pattern repeats 170 times: a collection endpoint, an item endpoint, the same five verbs on each. Pool works like VirtualService, which works like WafPolicy.

A generic tool taking an object_type parameter reaches all of them — including types added in the next Avi release.

GET/api/pool[/{uuid}]
POST/api/pool
PUT/api/pool/{uuid}
PATCH/api/pool/{uuid}
DELETE/api/pool/{uuid}
swap pool for any of 170 names — virtualservice, healthmonitor, sslkeyandcertificate — same lines, every time.
